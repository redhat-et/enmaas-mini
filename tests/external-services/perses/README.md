# Perses resources

The operational dashboards are generated by `monitoring.py`; these adjacent
JSON templates provide the gateway, trace and log views. See the
[monitoring contract](../../../docs/testing/external-services/monitoring.md).

The [original Praxis reference dashboards](https://github.com/praxis-proxy/experimental/tree/387c06d84f29b02b6fab985aa780686825582ee2/demos/ai-gateway/observability/perses)
are not provisioned or copied here. Their token-budget panels do not describe
PriceTag USD accounting. Their source remains available under the upstream
[Apache-2.0 license](https://github.com/praxis-proxy/experimental/blob/387c06d84f29b02b6fab985aa780686825582ee2/LICENSE).
